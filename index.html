Обновить данные Dotabuff

Данные обновляются автоматически раз в сутки — делать ничего не нужно. Если хотите свежие данные прямо сейчас, соберите их своим браузером:

  1. Нажмите «Скопировать скрипт».
  2. Откройте dotabuff.com/heroes, затем консоль браузера (F12 → Console).
  3. Вставьте скрипт и нажмите Enter. Chrome при первой вставке попросит ввести allow pasting.
  4. Через 1–3 минуты скачается data.js. Положите его рядом с index.html или перетащите сюда.
